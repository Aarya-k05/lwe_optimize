Failure caveat
---------------
The report does not specify the Q8 gain representation used here. Its C example uses integer coefficients in F and does not implement the 18-state LQR gain. Therefore arithmetic/control recovery for this explicit variant passes, but reference conformance and a definitive LWE-vs-CKKS comparison are not established. The simulated evaluation has access to the secret matrix/pad, so it can recover state values; this is not privacy-preserving untrusted-controller evaluation. The custom scheme is not standard HE and makes no security claim.
When validation fails, the generated plots are diagnostic measurements only and must not be interpreted as successful encrypted control.
